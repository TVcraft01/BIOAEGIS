# Code of Conduct

## Our standard

Contributors and maintainers are expected to communicate professionally, respectfully, and constructively.

Harassment, threats, discrimination, personal attacks, deliberate disruption, and inappropriate disclosure of private information are not acceptable.

## Project-specific expectations

BIOAEGIS is a defensive security research project. Do not use project discussions, issues, or pull requests to distribute real credentials, private data, destructive payloads, or instructions intended to compromise systems without authorization.

## Enforcement

Project maintainers may remove content, restrict participation, or close contributions that violate these expectations.
